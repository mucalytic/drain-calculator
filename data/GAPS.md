# Data gaps and unconfirmed values

`data/drains.json` is generated by `scripts/scrape_auno.py` from auno.org item
pages. Nothing in it is estimated. This file lists every value that is null, and
everything I could not confirm for Project Rubi-Ka (patch 18.4).

Source used: auno.org only (it answered plain HTTP requests). aogalaxy.com was
consulted only for the `Cyberdeck` requirement (item 3 below); it shows live
data with no patch history, so it was not used for values.

## Null fields

| Field | Nanos | Why |
|---|---|---|
| `levelRequirement` | all 32 | No item page has a level requirement row. The only requirements are nanoskills and profession (plus one flag on the Nanite Improved pair, see below). This is "no requirement on the item", not a missing value. |
| `selfBuffs[].nanoline` | all 16 Ransack and Plunder nanos | auno's name for this nanoline is wrong, see item 2 below. |

`condition: null`, `connector: null` and `value: null` (on a "not running"
requirement) mean "none", not "unknown".

## Not confirmed for 18.4 / Project Rubi-Ka

1. **Patch mapping.** auno's history for the 28 original drains shows a change
   at 15.9 and the next at 18.8.53; the Nanite Enhanced pair 17.2 then 18.8.53;
   the Nanite Improved pair 17.9 then 18.8.53. I use the last version before
   18.8.53 as "in force at 18.4". I can't verify that auno imported every patch
   in between, or that PRK has not changed these nanos itself.
2. **Self-buff nanoline name for Ransack/Plunder.** auno labels strain 138
   "Trader AC leech line A". That is wrong: these are not AC leeches. auno's
   own listing of strain 138 contains exactly the 16 Ransack and Plunder
   "Transfer" buffs and no AC nano (the real AC leeches, Siphon AC and Draw AC,
   are listed elsewhere). So `nanoline` is null for those 16 self-buffs, the
   grouping is carried by `nanolineStrainId: 138`, and auno's text is kept in
   `nanolineLabelOnAuno`. The true in-game name of strain 138 is not on the
   page. The 16 Deprive/Divest transfers are strain 137, "Divest skills effect".
3. **`Cyberdeck & 6`** on both Nanite Improved nanos (17.9). Recorded exactly as
   auno prints it. aogalaxy (live data, not 18.4) prints the same requirement
   as `Cyberdeck & 64`, so auno's 6 is most likely a bit number (bit 6 = 64),
   but neither page says so. "Cyberdeck" is the stat name both databases use;
   per the project owner a Trader has no access to a cyberdeck, so the name
   cannot be read literally. What sets this flag on a character, and whether a
   Trader on PRK can meet it, is not in the item data.
4. **Crystal for Plunder Skills (Nanite Improved)** is shown on the 17.9 page as
   "Nano Crystal (Divest Skills (Nanite Improved))" (id 275033). Recorded as shown.
5. **Stacking behaviour.** The pages give a stacking order number per nano and
   a nanoline. They do not state the rule the game applies (which order wins,
   what happens on a tie, whether the self-buff still lands when the target
   already has a better debuff). See the laddering write-up; those rules need
   confirming in game.

## Deliberately excluded

- **Shutdown Skills** (280050, "Theft Humidity" on live): a standalone Trader
  nano, not part of the skill-drain lines. It has its own nanoline, lasts 3
  seconds, and its self-buff adds no nanoskills.
- **Divest Skills (Spiritech Improved)** (302674): first appears in 18.8.53 and
  is usable only by NPC types 94-99. Not in the game at 18.4.
- **Nanoskill Deprival** (276403): no profession requirement, NCU 999, school
  "Space", 10 s. Not a Trader nano.
- **Divest Damage**, **Health Plunder**, AC and nano-point drains: not skill drains.
- The `... Drain` items (ids 3014xx / 3019xx): introduced in 18.8.53 as the
  target-side debuff. At 18.4 the debuff is on the drain nano itself.
